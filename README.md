# ProyectoLarvas
Detección y medición de larvas mediante IA

## Módulo de Calibración (`calibracion.py`)
Establece la relación píxel/centímetro mediante una interfaz gráfica interactiva, permitiendo aislar el área de interés (ROI) y calcular el área total del contenedor.
